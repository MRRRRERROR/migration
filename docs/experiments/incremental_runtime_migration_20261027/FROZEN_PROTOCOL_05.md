# 正式阶段冻结协议

实际活动根为服务器 `paired_abc_01`，控制器470406，沿用17:20加载的两个模型实例。六个预实验全部有效后自动进入正式30轮，期间无模型重启。版本清单以活动根formal_frozen_code.json及父根实际环境审计为准。本文件补充初始DESIGN.md的实施细节，不改变已冻结动作。

模型Qwen2.5-7B-Instruct，bf16，context9216，KV4GiB，batch8192，同步调度、batch-invariant、eager。生成temperature0、max_tokens4096、n1，正常EOS。length是输出预算截断；不称完全无输出长度限制的自然生成。物理0/1两张RTX5090，UUID及实际启动参数见服务清单。只做本地双卡，测量期间不卸载、不退出源端、不自动扩缩容。

统一入口路由取最小 `(running + waiting + reserved + 未观测入口请求, KV使用率)`；完全并列按逻辑request_id的SHA256确定。A/B/C完全相同。路由不读取提示词未来长度。请求泊松开放到达，不用完成驱动并发数，连接无并发上限。统一入口每个非幂等生成POST用新上游连接，不自动重试模糊失败。

B优先选择总在途差至少2时源端最早到达的可转移等待请求。资格包括：WAITING、computed/output均0、ever_scheduled=false、preemptions0、KV blocks0、无传输。目标KV<85%，空余blocks覆盖输入加1个block。实际detach在EngineCore边界再次检查，资格失效即原子拒绝并撤销目标预留；请求原地继续。接管保存同ID、arrival_time、参数和输出地址。被抢占后重新等待的请求排除。

C先执行同一B规则，再考虑运行迁移。1秒检查、状态最多旧2秒；同方向running差至少3并连续3次观察（约2秒跨度），选择已输出且computed上下文最短、至多4096token的候选。目标KV<85%，空余blocks覆盖当前上下文加512token。一次最多一个会话，结束后10秒冷却，同请求60秒防往返。迁移期间共享互斥；C运行冷却不禁用B等待规则。完成等待转移同时开启等待和运行冷却，完成运行会话只开启运行冷却。值在预实验前确定，正式不改。

源端lease配平以及原生source_release、dst_resume、migration_done等终态才确认迁移完成，不把RPC ACK当完成。404或MigrationOnly取消与用户请求失败分别统计。源block lease acquire/release、原生迁移阶段、控制器RPC/会话均保留。网络传输字节未实测，不用读取日志的字节数或缓存规模冒充。

容量中档0.5、高档2请求/秒，独立校准种子6300/6301。2是本次保守零抢占判据下已观测通过的高档；3请求/秒完成但出现17次抢占，不能称已证明持续发散或全局最大容量。早期HTTP500以及生成器启动扫描延迟有独立失败记录，不能当容量不足。修正后真实发送时序验收110/110完成、max lag0.104285秒。每轮质量max lag<=1秒且p99<=0.5秒是预先定义的发送有效性门槛，不是业务SLO。

预实验种子7101/7102，每档ABC一轮，六轮4653/4653完成。C共12次运行尝试，11完成1因请求正常结束取消；B/C同ID输出和finish_reason全一致。运行中动作存在且有效性通过，因此进入30轮；没有按预实验性能差异调参。

正式种子8101～8105。各种子、各负载ABC共享冻结清单、输入token IDs、生成参数和到达时间。1815去重原始ShareGPT文本使用目标聊天模板编码，128～4096token，均匀有放回抽样，不冒充10000个独立提示词。每轮600秒发送、固定600秒尾部；控制策略尾部保持运行，所有请求纳入结果。平衡交错顺序见formal_order.json。轮次间确认本实验请求/事务空、统一16token预热、清前缀缓存；模型持久在位。

主指标为全部已发送请求分母的E2E p95；失败或截止未完成没有有限完成时间，有限结果覆盖不足相应分位时不估出有限值。延迟从实际客户端发送计，另外保存计划时间和发送滞后。TTFT是首非空输出块，TPOT=(客户端完成−首非空块)/(输出token数−1)，是含尾部开销的客户端均值，不是逐token ITL。所有SSE块、token IDs、usage和finish_reason保留。

主比较逐种子C−B、B−A，负值表示更快。五种子都有效有限才计算平均与df4配对t区间；不以单条请求冒充独立重复。C决策的迁移对象、源端其他请求、目标端已有请求是事后分组，用同ID提取B，分组可重叠，不构成独立随机对照。无业务SLO，不事后找有利阈值。负结果同样保留。

关键错误、未解释请求丢失或截止未完成阻断后续轮次并留现场。外来GPU进程污染保留原轮次，停止发新请求并收尾本实验已发请求；不停止外来进程。事先允许污染解除后补一次，同种子同参数，新目录及原因记录；重复污染先停止诊断，不换卡抢资源。04污染轮及05补跑都保留。
